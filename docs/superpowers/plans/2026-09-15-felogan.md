# Felogan Slice 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Admin-only Felogan breakfast logging (rooms, cooks, menu, room servings) plus an after-login chooser between Felogan and Guesthouse Counter.

**Architecture:** Mirror `Ledger/`: EF entities on `AppDbContext`, `FeloganService` for catalog + servings, Minimal APIs under `/v1/felogan` with `.RequireRole(Roles.Admin)`, empty-table seed via `FeloganSeed`. Web UI stays one origin: login + chooser in `app.js`, Felogan screens in `felogan.js`.

**Tech Stack:** .NET 10, ASP.NET Core Minimal APIs, EF Core (Npgsql in run, InMemory in tests), ASP.NET Identity JWT, xUnit + `WebApplicationFactory`, static `wwwroot`.

**Spec:** `docs/superpowers/specs/2026-09-15-felogan-design.md`

## Global Constraints

- All `/v1/felogan/*` are Admin-only. Staff with a valid JWT get `403` `FORBIDDEN` (JWT `OnForbidden` already returns the envelope).
- Catalog **names are strings**, not C# enums. The only allowed menu `kind` values are `"plate"` and `"extra"`.
- Seed inserts only when that catalog table has **zero rows**. Never overwrite Admin edits.
- Active catalog names unique case-insensitively. Archive frees the name.
- Serving line display/totals use **snapshots**. Menu price edits do not rewrite old servings.
- `servedOn` and `?date=` / `range=day|week|month` use **Asia/Manila**. Week is Monday–Sunday (copy `LedgerService.WeekBounds`).
- JSON camelCase. Money max 2 decimal places. Note max 200. Name max 64.
- Error envelope unchanged: `{ error: { code, message, correlation_id } }`.
- Do not implement settlement, inventory, remaining packs, Paid Cook/Sham, or sheet import.
- Do not commit unless the user asks. Skip every Commit step until then.
- Tests: `dotnet test --project Hospitality.Api.Tests` (unsandboxed if testhost fails). C# changes need `dotnet run --project Hospitality.Api` restarted; static files refresh with cache-bust query strings.

            password = "AdminPass1!"
        });
        login.EnsureSuccessStatusCode();
        using var doc = JsonDocument.Parse(await login.Content.ReadAsStringAsync());
        client.DefaultRequestHeaders.Authorization =
            new AuthenticationHeaderValue("Bearer", doc.RootElement.GetProperty("access_token").GetString());
    }

    private static async Task AuthorizeStaffAsync(HttpClient client, string email, string username)
    {
        var register = await client.PostAsJsonAsync("/v1/auth/register", new
